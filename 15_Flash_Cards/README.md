# Flash Card
A flash Card app made in react using vite. Like a flash card you can hide and show answer and all the flash card questions and answer will dynamic changes as the question.json content changes while maintaining the same structure

# Features
- Dynamic Progress Bar
- Only need to change questions.json and everything will works fine
- Minimal look

# To use the app
Clone the repo
```
git clone https://github//
```

- Go into the directory if isn't already
```
 cd 15_Flash_Cards
```

- Run the server
```
npm run dev
```

## Note
question.json is located in `'public/question.json'`
